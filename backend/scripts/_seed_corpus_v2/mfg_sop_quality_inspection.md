# SOP: In-Process Quality Inspection — Line 7 Packaging

**Document ID:** WI-QA-101 | **Filename:** mfg_sop_quality_inspection.md | **Department:** Manufacturing
**Document Type:** SOP | **Version:** 3.2 | **Effective Date:** 2026-01-25
**Owner:** Quality Assurance Manager | **Access Classification:** Internal

## PURPOSE

This SOP defines in-process inspection steps for Line 7 packaging to ensure fill volume, seal
integrity, and label placement meet specification before cases are palletized.

## SAMPLING PLAN

Acceptance Quality Limit (AQL) for Line 7 is **0.65**, sampled per the standard AQL table for lot
sizes up to 3,200 units. First-article inspection requires 100% check of the first 20 units after
any changeover.

## FILL VOLUME CHECK

Target fill volume is 2.00L with a tolerance of ±0.02L, checked every 30 minutes using the
calibrated volumetric fixture. Any unit outside tolerance triggers a re-check of the prior 30
minutes of production before release.

## SEAL INTEGRITY CHECK

Seal strength is checked hourly using the pull-test fixture. **Minimum acceptable seal strength is
12N.** A failing seal test requires immediate notification to the Shift Lead and a hold on all
product since the last passing check.

## LABEL AND CODE VERIFICATION

Verify lot code, best-by date, and label placement on 5 consecutive units at the start of each
hour. A misprinted or missing lot code is an automatic reject — do not release for override without
Quality Engineer approval.

## NONCONFORMANCE HANDLING

Any lot exceeding the AQL 0.65 defect rate is placed on Quality Hold, tagged, and logged in the NCR
system within the shift. See SOP-MFG-104 if the finding requires a machine shutdown for
investigation.
